# 项目与工作区视图

## 布局与显示选项

项目目录支持卡片、看板、列表和时间线，共用项目卡片与属性组件。看板可按分组快速创建项目；列表的展开状态与动画使用公共实现。时间线复用甘特图的周、月、季度导航及日期更新逻辑。

工作区工作项视图支持列表、看板、日历、表格和时间线。各布局的分组、排序和显示属性以 `ISSUE_DISPLAY_FILTERS_BY_PAGE.workspace_issues.layoutOptions` 为准。看板按跨项目共享的状态类别分组，不使用某个项目的状态 ID 作为工作区分组。

创建视图可以选择布局，显示菜单随布局变化。另存为保存当前筛选表达式、布局及显示属性；布局正在切换时，使用最新请求的目标布局。保存快照与来源页面相互独立。

## 筛选与导出

筛选支持标题、正文、状态组、负责人、优先级、项目、标签、周期、模块及日期等字段。具有选项的字段可通过悬停展开快捷选择；标题与正文分别使用独立文本条件。排序字段与升降序是两个独立入口。

工作区视图可导出 CSV、XLSX 或 JSON。导出范围保留当前视图的条件与成员权限，排除草稿、归档和不符合范围的子工作项。异步导出完成后通过工作区鉴权的 API 下载，不向浏览器暴露对象存储的容器内部地址。

## 性能与交互

- 列表和表格通过共享窗口化工具仅渲染可见行，键盘导航仍按完整数据索引工作。
- 布局切换先保留旧内容退出，再等待新数据就绪后进入；快速返回不会强行显示骨架。请求超过延迟阈值才显示与布局相符的骨架屏。
- 看板使用 OverlayScrollbars 管理滚动，保留固定标题边界和按交互显示的滚动条。
- 下拉默认保持源数据顺序。视图切换器按完整选项名称计算宽度，受屏幕可用空间限制，不强制与触发按钮等宽。
- 表格当前工作项使用内侧描边，不改变单元格及文字的位置。
- 日期属性在当前年省略年份，跨年保留年份；完整日期通过提示显示。

## 验证

前端单元测试：

```sh
pnpm --filter web test
pnpm --filter @plane/blocks test
pnpm check:types
```

后端回归在独立 Docker 测试环境运行：

```sh
docker compose -f docker-compose-test.yml run --rm api-tests pytest \
  plane/tests/contract/app/test_workspace_view_layouts.py \
  plane/tests/unit/utils/test_issue_text_filters.py
```

浏览器回归应覆盖四种项目布局、五种工作项布局、筛选清除/保存、切换中另存为、导出权限、窄屏下拉及表格选中后位置稳定性。测试数据可以保留；清理环境时保留开发数据库和上传文件。

# 工作区分析与图表

工作区分析包含概览、项目、用户、工作项、周期、模块与收集七页。所有统计都读取实际业务记录；仅统计当前用户已加入且仍有效、未归档的项目。项目筛选会与权限范围求交集，不能扩大数据访问范围。

## 概览看板

概览保留原有八项统计：工作项、项目、周期、收集、用户、管理员、成员和访客。前四项为业务规模，后四项为成员结构，统计块使用一致字号与间距，点击链接到相应分析页。选择顶部项目筛选后，各区域使用相同的项目集合。

下方展示新增／完成趋势、活跃项目和项目进展表。新增按创建日期分月，完成按实际完成日期分月；跨月创建和完成的工作项会分别计入对应月份，不以“创建月份内当前处于已完成状态”代替完成事件。顶部项目与时间筛选共同作用于分析，默认全部时间，支持昨天、最近 7 天、30 天和 3 个月，自定义范围包含起止两天；通过下拉选择“全部时间”恢复，项目选择器保留自身选择操作。工作项与收集按创建日期限定样本；项目、周期和成员结构保留当前总数，避免把老成员误显示为零。趋势的完成系列按完成事件日期统计，进度与明细按所选创建样本的当前状态统计，时间筛选入口展示当前范围。

活跃项目保留原有图标容器、名称与完成率标签，仅补充细进度和已完成／总数；已取消不计入已完成。活跃项目展示项目图标、名称、已完成／总数和完成率，点击进入真实项目。进展表复用项目分析页的表格、搜索与多格式导出能力，展示项目、工作项、周期、模块及完成率；独立项目分析页保留完整列。

## 明细与统计接口

- `advance-analytics/`：概览及工作项统计。
- `advance-analytics-charts/`：真实趋势与自定义分组；工作项数、史诗数及估算点分别聚合。数字估算值参与求和，非数字标签不会强行转换。
- `advance-analytics-details/?type=projects|users|cycles|modules|intake`：五类明细页的汇总、图表和表格数据。用户统计不把机器人或“未分配”占位行计为真实成员；周期、模块进度来自实际关联工作项。

尚未有可靠业务数据的项目健康度等指标不使用模拟值补齐。原型中的演示数据不进入产品接口。

界面按扁平结构排版，避免重复卡片边框；八项统计保持相同字号和间距。项目进展的标题、记录数、搜索和导出使用一行工具栏，数值列的表头和内容右对齐。零工作项项目不显示空进度或无意义的百分比。

## 公共图表与加载

柱状、面积、折线、饼图、雷达与矩形树图继续使用现有 Recharts 公共组件。统一紧凑提示、数字格式、坐标轴、网格、图例和 300ms 动画，响应系统的减少动态效果偏好。默认序列采用克制的主题配色；优先级、状态等语义颜色保持有明确业务含义。个人资料和周期／模块进度图也复用同一套展示规则。

`AsyncContent` 复用 `useDelayedLoading`：请求开始即保留相应空间，超过 180ms 才显示与内容结构匹配的骨架；数据返回后再播放内容入场，避免 Tab 动画结束后只剩空白。分析页关闭外层重复的面板动画，保留 Tab 指示器动画。错误显示明确的重试入口，不以零统计伪装失败。

## 验证

前端测试覆盖八项统计及页面链接、项目筛选参数、空项目进度、嵌入表格、CSV／Excel／JSON 搜索结果、快慢加载和下一轮请求的延迟重置。公共图表测试覆盖零值、数字格式、系列顺序、重复／无关数据过滤，以及减少动态效果切换。后端契约测试覆盖五页统计、权限隔离、聚合口径及跨月完成事件。

项目进展保留系统表格的表头背景和行分隔线，不额外包卡片。所有分析表格共用主色“导出”下拉按钮，支持 CSV、Excel（XLSX）、JSON，均只导出当前搜索筛选后的行和可导出列；CSV 文本防止被表格软件识别为公式。活跃项目行高约 47px，标题到列表间距 8px，进度轨道使用主题边框色以区别页面背景。

Excel 使用真实 XLSX 文件，冻结表头并按内容设置列宽；中文、数字零值和换行按原值保留，文本显式写为字符串，避免公式解释。导出库按需加载，下载失败显示可重试错误。时间范围统一使用 `custom:YYYY-MM-DD:YYYY-MM-DD`，无效日期及倒置范围返回 400，避免静默导出全部时间。

## 独立预览页

新增 `project-progress-preview`（项目进展）和 `quick-insights-preview`（随手洞察）两个 Tab，保留原有七个分析页，待调试确认后再决定替换。

- 项目进展复用项目统计接口和缓存，展示工作项数、完成数及加权完成率；支持按工作项数／完成率对比，选择图例联动明细，并可进入项目。
- 随手洞察复用自定义分析接口，支持状态、优先级、项目、负责人维度及工作项数／估算点数指标。图表与分组表格双向选择，支持收起洞察。多人负责的工作项计入各负责人分组，因此标注为分组总计。
- 两页共用项目与时间范围筛选、延迟加载、错误重试和搜索结果导出。图表每页最多显示 12 个分组，其余通过分页查看；明细保留完整结果。
- 预览图表参考 shadcn Chart 的 Recharts 组合方式，采用圆角柱条、细网格、无轴线、主题配色及紧凑 tooltip。图例提供键盘可操作的筛选按钮。分类比较组件在预览页使用，趋势与 tooltip 组件和正式页复用。
- 分析导出菜单宽度为 120px，CSV／Excel／JSON 分别使用 Table2／FileSpreadsheet／Braces 图标。

项目进展预览提供 2026 年 1–8 月的固定演示数据，可切换真实数据。演示数据明确标注，不受顶部筛选影响，不写入后台、不参与导出。

创建与解决为按月离散计数，使用并列柱状图，共用零基线、非堆叠、组内间距小于组间间距，不以重叠面积或平滑插值暗示未经观测的变化。

## 正式图表迁移与配色

概览、工作项和项目分析弹窗的创建／解决对比复用 `CreatedResolvedChart`，采用蓝／绿并列柱、零基线和交互图例。两个预览页复用正式图表组件，演示数据仅存在于预览容器。图表的表达审查与统计口径见 [图表审查](analytics-chart-audit.md)。

配色采用 Apple HIG 当前系统色表的浅／深色 Web sRGB 对应值，由 `APPLE_CHART_COLORS` 统一生成分类和语义色。图形、图例和 Tooltip 使用同一映射；自定义项目状态色保留。Tooltip 紧凑显示，颜色不因悬浮其他序列而降低透明度。用户、周期和模块横向图根据条目数调整高度，长中文标签省略并保留完整标题，坐标标题预留独立空间。

## 统计口径统一

完成率排除取消项，收件箱统计完整五种当前状态；负责人／标签分组注明非互斥。创建／解决趋势在工作区和项目弹窗共用后端 `analytics_trends.py`，按独立日期聚合，响应提供实际区间与日／月粒度。燃尽图保留真实时间间隔和缺测空值，明确按当前范围回算而非历史快照。具体页面、公式和验证见 [图表口径修复记录](analytics-chart-audit.md)。
